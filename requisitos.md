# Projeto Catálogo de Filmes
**Nome do projeto:** Catálogo de filmes
**Equipe de Desenvolvimento:** Natalia Gamero Scognamiglio

## **1. Visão Geral do Sistema (Escopo)**

O sistema será desenvolvido para ajudar o usuário a organizar sua coleção pessoal de filmes. Nele, será possível fazer login e cadastrar filmes, colocando informações como nome, ano de lançamento, gênero, nota e imagem da capa. O usuário também poderá visualizar os filmes cadastrados em uma galeria, além de editar ou excluir os filmes quando quiser.
Por enquanto, o sistema terá apenas essas funções de organização da coleção, sem opções de compartilhar os filmes com outras pessoas ou outras funcionalidades adicionais.

## **2. Requisitos Funcionais (RF)**

**RF01** – O sistema deve permitir que o usuário faça login com usuário e senha.  
**RF02** O sistema deve permitir cadastrar um filme.  
**RF03** O sistema deve permitir informar o nome do filme.  
**RF04** O sistema deve permitir informar o ano de lançamento.  
**RF05** O sistema deve permitir informar o gênero do filme.  
**RF06** O sistema deve permitir informar uma nota de 0 a 10.  
**RF07** O sistema deve permitir adicionar uma imagem da capa do filme.  
**RF08** O sistema deve exibir os filmes cadastrados em uma galeria.  
**RF09** O sistema deve permitir editar as informações de um filme.  
**RF10** O sistema deve permitir excluir um filme cadastrado.

## **3. Requisitos Não Funcionais (RNF)**

**RNF01** O sistema deve possuir autenticação por login e senha para proteger o acesso à coleção.

**RNF02** O sistema deve possuir uma interface simples e organizada para facilitar o uso.

**RNF03** O sistema deve apresentar as capas dos filmes de forma visual e organizada na galeria.
